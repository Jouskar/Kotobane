# Code of Conduct

Kotobane is a welcoming project for contributors of every background and
experience level. Be respectful, constructive, and considerate in issues,
pull requests, and discussions.

Harassment, personal attacks, discrimination, sexualized language, and other
unwelcome conduct are not acceptable. Project maintainers may remove content
or participation that violates these expectations.

To report a concern privately, email the maintainer listed in the repository’s
GitHub profile. Reports will be handled discreetly and fairly.
